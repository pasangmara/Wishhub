# Wish Hub: USA Client Presentation Video Kit

A production kit for a ~88-second B2B presentation video (plus a 30s social cut), built with **Google Flow (Veo 3)**.

| File | What it is |
|---|---|
| `01-content-breakdown.md` | Everything in the pitch deck, structured, plus what to focus on |
| `02-script-and-storyboard.md` | Scene-by-scene script: visuals, on-screen text, VO, music, SFX |
| `03-flow-prompts.md` | Copy-paste Veo 3 prompts for Google Flow (clips C1–C10) |
| `04-voiceover.txt` | Clean narrator script for ElevenLabs / TTS |
| `05-music-sfx-brief.md` | Music arc + timestamped SFX list + mix levels |
| `06-edit-guide.md` | Prep checklist, timeline, style rules, exports, QA |
| `assets/` | Reference stills for Flow, the transparent logo, hook overlays, 12 US wish cards (+ generator), a 4K card grid, motion-graphic sources (`motion/`), and the scratch voiceover MP3s (`voiceover/`) |

**Story arc:** Hook (missed moment) → Turn ("We remember it for you") → Card showcase → How it works →
Your brand → Automation → Free trial / demo offer → Emotional close + CTA.

**Workflow:** make the US card set + screen recordings → generate the C1/C2 test clips in Flow → generate the rest →
record VO → add music/SFX → edit → export.
